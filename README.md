# Problem Statement

Design an AI system for industrial monitoring and automation to improve efficiency using IoT devices and embedded controllers. The system should:

Automate industrial equipment
Monitor machine performance
Predict failures using predictive maintenance
Reduce downtime
Improve operational efficiency

The AI tools used for comparison:

ChatGPT
Google Gemini
Microsoft Copilot
# 1. Comparative Analysis Prompt
Prompt

“Compare traditional industrial monitoring systems with AI-powered IoT-based automation systems in terms of efficiency, maintenance cost, scalability, real-time monitoring, and predictive maintenance capabilities.”

Expected Output

The AI should provide:

Differences between conventional and AI systems
Benefits of AI automation
Comparative table or analysis
Industrial use cases
